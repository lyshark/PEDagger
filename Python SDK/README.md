PE Dagger Server

Windows PE32 / PE32+ Static Parsing and Rewriting Service

After startup, it only monitors a single port and provides interfaces via HTTP + JSON. Features such as header parsing, import/export table analysis, disassembly, section rewriting, resource and relocation reconstruction, and signature auditing can be invoked with a single request. Built-in CORS allows direct cross-origin connections from browsers, and supports multi-session isolation for concurrency.
